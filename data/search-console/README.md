- `performance-queries-last-3-months.csv`
- `performance-pages-last-3-months.csv`
- `performance-queries-compare.csv`
- `performance-pages-compare.csv`
- `indexing-page-with-redirect.csv`

- CSV heeft voorkeur.

- Er is geen Google-login nodig.
- Er zijn geen tokens of credentials nodig.
